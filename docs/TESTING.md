# Testing

- CI runs Statix, checks Alejandra formatting, and builds documentation through flake outputs.
- Evaluate affected NixOS and Home Manager options before attempting expensive system builds.
- When the known `superfreq`/nixpkgs `services.watt` duplicate blocks evaluation, focused desktop checks can disable `services/hardware/watt.nix` in a temporary `extendModules` harness. This does not verify a complete system build.
- For shell-suite changes, evaluate both module scopes for `oxi`, `noctalia`, and `none`, including disabled shell/locker/greetd and user-setting overrides. Check startup commands, bindings, session packages, PAM policy, and that only one sleep watcher is generated.
- Local checks use `path:.` to include new untracked modules and the deliberately synchronized ignored lock. Run `nix run path:.#lint -- check`, `nix run path:.#format -- --check .`, and `nix build path:.#docs --no-link --no-write-lock-file` (with `pipe-operators` enabled).
- Verify binary-cache compatibility by comparing system and Home Manager package derivation paths with the exact pinned, unoverlaid nixpkgs input.
- Use `nix build --dry-run` with the relevant substituter enabled to distinguish cache downloads from local builds.
- Fetch compositor, portal, and Mesa with `nix build --no-link --max-jobs 0` to prove they require no local source builds.
- Validate generated desktop configuration with the pinned compositor where supported. Hyprland's `--verify-config` executes Lua `hl.exec_cmd` calls; stub that function in an isolated validation config to avoid running startup applications. Runtime login and rendering still need verification after activating a system generation.
- For Hyprland kiosk changes, build `services.oxisession.package` to run its Rust tests, including watchdog process-group ownership and fail-closed teardown. Launch its installed wrapper from a cleared environment matching greetd's PAM boundary, then compare the resulting environment and Lua with resolved Home Manager defaults and input/cursor/device overrides. Decode configured cursor shapes with the pinned Xcursor library to check asset lookup; daemon environment assertions cannot verify greeter inheritance. Check Cage, Noctalia, disabled greetd, and compositor-disabled fallbacks. Validate both the shared Lua settings and the kiosk's runtime-generated Lua with the pinned compositor; ensure cursor and greeter commands wait for `hyprland.start`.
- Build generated Oxibar/authentication TOML and greetd configuration to check serialization. Runtime authentication checks require a test system: inspect `journalctl -u greetd`, run `oxilock --check` for protocol support, and verify unlock and sleep/resume there.
- For hardware-authentication changes, evaluate disabled, enabled, tools-only, and overridden PAM settings against both stable and unstable inputs, plus shared-module evaluation in Home Manager. Inspect generated PAM rules and hardware-service settings. Actual enrollment, key authentication, and password fallback require a test system with the hardware attached.
